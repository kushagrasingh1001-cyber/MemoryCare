# MemoryCare fixes in this build

- One patient group invite code is generated once at patient signup and remains visible on Family.
- The same code can link up to four caregiver/family accounts.
- Family page now shows the patient and linked caregivers in real time.
- Caregivers retain access to the patient dashboard/progress and reminder scheduling.
- Five cognitive games: Memory Match, Odd One Out, Daily Routine, Word Recall, Number Sequence.
- Difficulty is Level 1-5. A completed game at >=80% raises that game one level for the next play; <40% lowers one level.
- Odd One Out grows from 4 pictures at Level 1 to 6 at Level 2, then 8/10/12.
- Every game shows Back to Home after completion.
