# MemoryCare V8 – Gallery & Game Flow Polish

Changes from V7:
- Patient gallery photos open in a full-screen viewer when tapped.
- Full-screen viewer includes Back and Close controls.
- Added Friends to the caregiver gallery category selector.
- All five games now show Play Again after completion.
- When adaptive difficulty actually raises a level, the replay button is labelled Next Level with the new level number.
- Back to Home remains available after every game.

The Firebase data model is unchanged; existing V7 data remains compatible.
