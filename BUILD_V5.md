# MemoryCare V5 - UX rebuild
- Patient home redesigned with four consistent action cards.
- Full Hindi/English strings added for patient home, gallery, reminder labels and navigation.
- Memory Gallery: caregiver uploads photo + title + people + story/category; patient gets recall/reveal experience.
- Number Sequence: answer is no longer auto-submitted; Clear and Submit controls added.
- Adaptive difficulty now uses two consecutive scores: both >=80% level up; both <=50% level down.
- Patient reminders now explain their purpose, show upcoming/completed reminders, and display a full-screen due reminder.
- Caregiver reminder creator now supports type, date/time and instructions.
- UI refreshed with consistent cards, stronger hierarchy, icon tiles, feedback and elderly-friendly sizing.
